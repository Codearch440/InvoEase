 0# InvoEase – Freelance Invoice Generator

A sleek, browser-based invoice generator built with **HTML, CSS, and JavaScript**.  
InvoEase helps freelancers and small businesses create **GST-compliant invoices** with **SGST/CGST calculation**, **discounts**, and **PDF export**, all within a simple and responsive interface.

---

## 🚀 Features

✅ Dynamic item management (add/remove services or products)  
✅ Dual GST fields – SGST and CGST, calculated separately  
✅ Freelancer and client GSTIN / Tax ID fields  
✅ Automatic subtotal, tax, and total calculation  
✅ Discount and currency selector  
✅ Real-time invoice preview  
✅ Export as **printable A4 PDF** using jsPDF and html2canvas  
✅ Fully responsive and minimal UI

## 🛠️ Technologies Used

- **HTML5** – Structure and input fields  
- **CSS3** – Styling and responsive layout  
- **Vanilla JavaScript (ES6)** – Dynamic logic and calculations  
- **jsPDF** & **html2canvas** – PDF export and preview rendering
